# SQL Server 脚本说明

本目录提供《数据库原理与应用》课程作业可直接提交的 SQL Server 数据库后台脚本。

## 执行顺序

1. `01_schema.sql`：创建 `ForeignTradeConnectDB` 数据库和完整表结构。
2. `02_seed_data.sql`：写入答辩演示用样例数据。

建议在 SQL Server Management Studio 中按顺序执行。若数据库已存在，先备份后再按实验环境要求删除旧库或调整 `01_schema.sql` 的 `CREATE DATABASE` 语句。

## 覆盖范围

`01_schema.sql` 覆盖报告中的核心后台表，并补充采购订单后台表，共 83 张表，主要包括：

- 登录认证：`sys_user`、`sys_permission`、`sys_permission_group`、用户权限关系、登录审计。
- 店铺客户：销售平台、运营组、店铺、店铺分配、客户、客户联系人。
- 商品资料：商品、SKU/变体、季节、图片、属性、运营跟踪字段与投影。
- 库存事实：仓库、导入批次、库存单据、库存单据行、库存流水、当前库存余额、期间锁定。
- 采购事实：供应商、采购订单、采购订单明细，用于采购在途和补货追踪。
- 销售事实：销售单据、销售单据行、销售流水、销售与库存履约关联。
- 价格成本：价格档案、价格值、价格投影、价格变更、成本层、成本调整、成本流水和成本余额投影。
- 财务事实：账簿、期间、科目、维度、财务单据、凭证、余额快照、关账快照、操作日志。
- 报表查询：指标定义、指标版本、查询模型、查询字段、查询快照和各类汇总报表表。
- 外部数据迁移：外部源类型、迁移计划、迁移运行、原始记录、暂存记录、映射、问题和对账报告。

`02_seed_data.sql` 写入了最小演示链路：

- 管理员、商品运营、库存人员、报表人员和权限组。
- 店铺、客户、商品、SKU、仓库。
- 供应商、采购订单和采购在途明细。
- 库存入库/出库单据、库存流水、当前库存余额。
- 销售订单、销售明细、销售流水。
- 销售汇总和库存汇总两个报表查询模型、指标版本和快照。

## 说明

课程报告中的“建表代码（SQL Server）”与 `01_schema.sql` 保持一致；后端 Django 原型当前使用 SQLite 便于本地启动，课程提交和数据库后台验收以本目录 SQL Server 脚本为准。
